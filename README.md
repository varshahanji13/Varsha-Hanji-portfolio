# Varsha Hanji — Portfolio

A modern, responsive React/Vite portfolio for Varsha Hanji.

## Run locally

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. In the terminal:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Personal details to edit

Open `src/main.jsx` and replace:
- `your.email@example.com`
- LinkedIn URL
- placeholder GitHub links for projects
- project links where needed

## Resume

Place your PDF resume at:

`public/resume.pdf`

Create the `public` folder if it doesn't exist.

## Build for deployment

```bash
npm run build
```

The production files will be generated in `dist/`.
